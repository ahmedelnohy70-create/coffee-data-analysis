# coffee-data-analysis
Project Overview:
Designed and developed a comprehensive interactive dashboard using Microsoft Excel to analyze and visualize coffee sales data. The project focuses on transforming raw transactional data into actionable insights to monitor business performance across different years and product categories.
​Key Features & Insights:
​Time-Series Analysis: Visualized "Sales by Year" using line charts to track revenue trends between 2024 and 2025.
​Product Performance: Created a "Sales by Coffee Name" bar chart to identify top-selling beverages, such as Latte, Americano, and Cappuccino.
​Payment Method Distribution: Integrated a "Sales by Cash Type" pie chart to analyze the percentage of transactions made via Card vs. Cash.
​Dynamic Interactivity: Implemented multi-layered Slicers (Year, Coffee Name, and Cash Type), allowing users to filter the entire dashboard and perform deep-dive analysis effortlessly.
​Technical Skills Applied:
​Data Cleaning & Structuring: Organizing "Main Data" into multiple Pivot Tables to power the visualizations.
​Advanced Data Visualization: Utilizing professional design principles to create a clean, user-friendly interface.
​Pivot Tables & Slicers: Leveraging Excel’s core analytical tools for dynamic reporting.
